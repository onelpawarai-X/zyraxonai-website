### Design Requirements

**Theme:** Dark mode (primary: #0a0a0f, accent: #00f5ff cyan)
**Font:** Inter or system font stack
**Style:** Modern, futuristic, clean
**Animations:** Smooth scroll, hover effects on cards, fade-in on scroll
**Responsive:** Mobile-first, works perfectly on all screen sizes
**Icons:** Use SVG icons inline (no external icon libraries)
**Colors:**
- Background: #0a0a0f (almost black)
- Card background: #111827
- Primary accent: #00f5ff (cyan)
- Secondary accent: #7c3aed (purple)
- Text: #ffffff
- Muted text: #9ca3af

### Technical Requirements

1. Single file: `index.html` (all CSS + JS inline)
2. No external dependencies (no CDN, no frameworks)
3. Smooth scroll navigation
4. Mobile responsive
5. Download buttons MUST work — link to actual GitHub release files
6. GitHub stars count should be fetched dynamically (optional, can use badge)
7. Dark theme only
8. Fast loading (no heavy images, use CSS gradients/shapes)
9. Add meta tags for SEO (title, description, og:image, twitter:card)
10. Add favicon (can use emoji or SVG)

### Extra Features (if possible)

- Typing animation in hero section
- Parallax scrolling effect
- Card hover animations (scale + glow)
- Terminal animation showing ZYRAXON commands
- Smooth section transitions
- "Back to top" button
