================================================================================
  HOW IT ALL CONNECTS
================================================================================

  The agent runtime loads the 30 built-in tools first. Through self_evolve it
  attaches the 9 MCP servers (156 functions). When ZYRAXON X boots, the x-tool
  registry registers all 353 vehicle/world tool classes. Every layer shares
  ZyraxonMemory and ZyraxonGraph so skills learned in one domain transfer to
  every other domain.
